# DevFolio — Personal Developer Portfolio

A clean, responsive developer portfolio built with **semantic HTML**, a **CSS custom-property colour system**, **Flexbox**, **CSS Grid**, and **media queries** — no frameworks, no JavaScript, just the web platform.

## Live URL

🔗 **https://hamsashaikh-source.github.io/devfolio/**

> Replace `hamsashaikh-source` with your actual GitHub username after deploying.

---

## Features

- Semantic HTML structure (`<header>`, `<main>`, `<footer>`, `<section>`)
- CSS custom properties for colours and typography
- Flexbox for the header / navigation row
- CSS Grid for the responsive projects section
- Mobile-first responsive design with `@media (min-width: ...)` breakpoints
- Flexible images with `max-width: 100%`
- Sticky header, hover states, smooth scrolling

## Run Locally

No build step required — open `index.html` in any browser:

```bash
# Clone the repo
git clone https://github.com/HamzaShaikh-source/devfolio.git
cd devfolio

# Open in browser (macOS)
open index.html

# Open in browser (Windows)
start index.html

# Open in browser (Linux)
xdg-open index.html
```

## Deployment

The site is deployed on **GitHub Pages**:

1. Push to the `main` branch
2. Go to **Settings → Pages → Source: Deploy from a branch → branch: `main`, folder: `/ (root)`**
3. Wait ~1 minute for the build to complete
